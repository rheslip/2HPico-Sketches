# Mutable Instruments Braids for the 2HPico

See comments at the top of the sketch for usage instructions

This sketch uses the ArduinoMI BRAIDS library. It seems more stable than the Synth_Braids library. The Synth_Braids sketch is still useful as an example of how to use the pico-audio (Teensy Audio) framework.

Dependencies:

2HPico library included in this repository - install it in your Arduino/Libraries directory. updated 2/17/2026

Adafruit Neopixel library

BRAIDS and STMLIB libraries included in this repository - slightly tweeked versions of https://github.com/poetaster/arduinoMI
