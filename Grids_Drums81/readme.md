Feb 27/2026 - this is Grids_drums modified with a much larger 9x9 drum map. Combines Mutable patterns, Phaserville patterns and some patterns created with ChatGPT. The map is a bit scrambled so it won't sound exactly like the Mutable patterns even when they are selected. The pattern interpolation code uses adjacent maps and they are no longer in the same positions with the expanded map.

An idea is to create some new maps from this one but with the pattern groups shifted around - interpolating on a different arrangment will generate yet more new patterns.
